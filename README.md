# Note & Do

Primeira versão funcional baseada nas telas apresentadas no Figma.

## Como usar

1. Extraia os arquivos.
2. Abra `index.html` no navegador.
3. Para publicar no GitHub, envie `index.html`, `style.css`, `script.js` e a pasta `assets`.

## Funcionalidades

- Página inicial
- Lista de notas
- Criação de notas
- Persistência no `localStorage`
- Calendário
- Perfil
- Navegação responsiva
- Interface em tons de rosa baseada no protótipo

> Esta é uma primeira versão. Os detalhes visuais podem ser refinados quando houver acesso às telas completas/exportadas do Figma.
